# 项目背景与个人贡献

## 所属项目

本仓库源于深圳技术大学 × 腾讯 Mini Project 3“性能工程 Skill 评估专项”的课程实践。完整项目组面向多个 Skill 场景建立统一评测规范；Code Review 只是其中一个子方向，本仓库不能代表项目组的全部成果。

## Code Review 子方向

子方向关注代码审查 Skill 是否能够被模型识别、正确执行，并在不同模型条件下稳定提升缺陷发现质量。课程阶段围绕资产冻结、D0/C_auto/C_forced 对照、运行证据、Judge、Qualification、Bad Case 归因和复测闭环开展工作。

课程报告曾记录该子方向对 6 个 Skill 进行双模型评测、每个 Skill 覆盖 32—33 条用例。由于原始运行、私有 GT、Judge 校准和授权材料未随本仓库发布，这些数字只用于说明历史工作规模，不作为本开源版本可复现的性能结论。

## 与完整项目组资料的区别

本仓库只保留可公开重构的通用方法与原创演示资产，不包含：

- 项目组其他子方向的实现与成绩；
- 会议记录、日报、成员个人材料；
- 私有 Holdout、GT、Evaluator-only 文件和真实提供商原始记录；
- 来源或再分发许可未确认的第三方 Skill；
- 课程报告中的未经公开数据支撑的模型排名结论。

这种边界既保护团队成果，也让公开用户能复现仓库内的每一项声明。
