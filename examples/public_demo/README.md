# Public offline demo

This demo uses an original synthetic Python case, an original example Skill, and a
checked-in replay response. It requires no model credentials and makes no claim
about the performance of any commercial model.

The three conditions have distinct meanings:

- `D0`: no Skill is supplied;
- `C_auto`: the runtime may discover and activate the Skill;
- `C_forced`: the Skill is explicitly loaded before the task.

The replay response exists to demonstrate evidence capture, judging,
qualification, attribution, and report generation. It is not benchmark data.
